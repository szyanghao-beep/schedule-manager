# 日程管理 v2.1.0 · 文档资料包

本文件夹汇集了「日程管理」软件的宣传资料、用户手册与培训资料，供发布、推广、培训和验收使用。

## 📁 文件一览

| 类型 | 文件 | 说明 |
|------|------|------|
| 宣传资料 | `宣传资料/日程管理工具V2.1.0-产品介绍V1.0.pdf` | 图文并茂的产品宣传册（PDF，含四象限、时间块、工作流等示意图） |
| 用户手册 | `用户手册/用户手册.pdf` | 面向零基础用户的完整使用手册（PDF，15 章，从安装到常见问题） |
| 培训 PPT | `培训资料/日程管理-培训PPT.pptx` | 培训课件（16:9，15 页，含培训目标、核心概念、操作演示） |
| 培训考卷 | `培训资料/培训考卷.pdf` | 培训效果考核试卷（15 题 / 100 分，含答题卡与参考答案） |

## 📖 各资料用途

- **宣传资料**：用于向潜在用户介绍产品价值与亮点，配合发布会、官网、社群推广。
- **用户手册**：随软件一起提供给最终用户，任何没有电脑基础的人都能照着操作。
- **培训 PPT**：用于内部或用户培训时的现场授课。
- **培训考卷**：培训结束后发放，验证培训效果（及格线 60 分）。

## 🔧 源文件与重新生成

各 PDF 均由同名 HTML 文件（配合 `_assets/doc.css` 统一样式）通过 Electron 渲染生成；PPT 由 `_build-ppt.js` 生成。如需修改后重新生成：

```bash
# 重新生成 PDF（需 Electron，已随项目安装）
npx electron README/_build-pdf.js README/宣传资料/宣传资料.html README/宣传资料/日程管理工具V2.1.0-产品介绍V1.0.pdf
npx electron README/_build-pdf.js README/用户手册/用户手册.html README/用户手册/用户手册.pdf
npx electron README/_build-pdf.js README/培训资料/培训考卷.html README/培训资料/培训考卷.pdf

# 重新生成 PPT（需 pptxgenjs）
node README/培训资料/_build-ppt.js
```

> 说明：`_build-pdf.js`、`_build-ppt.js`、`_assets/doc.css` 及各个 `.html` 为生成源文件，不属于应用本体，仅供维护文档时使用。
