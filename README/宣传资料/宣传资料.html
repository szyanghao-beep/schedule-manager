它是什么

日程管理是一款本地优先的个人日程与任务管理软件。你可以用它记录每天的日程、管理待办清单，并借助四象限、时间块、GTD 收件箱、周回顾等方法，把一天安排得井井有条。

桌面端一键安装，安卓端扫码同账号登录即可多设备同步，数据安全掌握在自己手中。

适合谁

  • 职场人士：会议、任务、截止日不再遗漏
  • 学生党：课程、作业、复习计划一目了然
  • 自由职业者：自己当老板，更要管好时间

📥 捕捉：别让大脑当硬盘

任何时刻按下 Ctrl+Shift+N 或点「快速捕捉」，把一闪而过的想法先丢进收件箱，几秒钟就完成，不打断手头的事。

⏱ 排程：把「要做」变成「几点做」

打开「今日规划」，系统会按截止时间、四象限、优先级，自动把带预估耗时的待办填入当天工作时段，一键应用即生成时间块日程。

💡 关键思想
时间管理的本质不是「做得更多」，而是「在正确的时间，专注地做正确的事」。

两个核心方法

① 四象限：分清轻重缓急

软件会根据你填写的重要性（重要/不重要）和紧急性（由截止时间自动判断），把待办自动归入四个象限，并用颜色徽标标出。

  • 待办列表按 Q1 → Q4 自动排序，重要紧急的永远排在最前面。
  • 支持按象限筛选，聚焦处理某一类事务。
  • 统计页展示四象限分布趋势，帮你养成「多做重要不紧急」的习惯。

② 时间块：给任务预约时间

给待办设定一个预估耗时（15 分钟 ~ 4 小时），「今日规划」会在当天 9:00–18:00 的工作时段里，按槽位自动为它预约一段不冲突的时间，形成一张「今日时间线」。

✅ 好处
每天开始前就知道「几点做什么」，减少临时决策，注意力更集中。

数据安全，交给自己掌控

🔒 本地优先，不依赖云端

所有数据默认保存在你的电脑本地，联网与否都能正常使用。同步功能是可选项，只有你主动登录才会上传。

💾 自动保存 + 自动备份

每次修改自动落盘，并采用「先写临时文件再替换」的原子写盘，避免断电损坏；系统还自动保留最近 10 份历史备份，可一键恢复。

🛡️ 账号安全

同步登录令牌用系统安全存储加密保存，不明文落盘；密码经服务端校验，多用户数据严格隔离。

🔁 同步冲突自动仲裁

多设备同时改同一条记录时，采用「最后编辑优先」的规则自动合并，旧版本不会覆盖新内容；删除也以墓碑方式同步，不会死灰复燃。

数据可以自由进出

能力说明
📤 导出一键把全部数据导出为 JSON 文件，可自行留存或迁移

三步开始使用

1
安装：双击「日程管理 Setup 2.1.0.exe」按提示完成安装（可选安装目录、创建桌面/开始菜单快捷方式）。
2
启动：从桌面图标或开始菜单打开。软件默认已内置「工作 / 生活 / 学习」三个分类，可直接开始记录。
3
开始记录：点「+ 新增日程」安排会议；点「+ 新增待办」记下任务；按 Ctrl+Shift+N 快速捕捉想法。

🔗 想用手机同步？（可选）

桌面端「设置 → 同步」填写服务器地址并注册 / 登录；手机端登录同一账号，即可自动同步。未配置服务器时，所有功能照常离线使用。
