### A. 日历增强（A1–A7）

| 编号 | 功能 | 落地要点 |
|------|------|----------|
| A1 | 农历显示 | 接入 `lunar-javascript`（vendored `shared/vendor/lunar.js`），月/日视图显示农历日期 |
| A2 | 二十四节气 | 月/日视图标注节气，今日规划同步显示 |
| A3 | 法定节假日 + 调休 | `getHoliday` / `isWorkday` / `isRestDay` 内置 2026 数据，标「休 / 班」徽标 |

### 3.2 发现并修复的 Bug

1. **预算漏计未分类支出**（真实业务 Bug）
   - 现象：`budgetStatus` 计算「总预算」时，`categoryId=null` 的未分类支出被丢弃，导致总预算不超支却实际超支。
   - 修复：`shared/bookkeeping.js` 累加未分类支出到总预算；新增回归测试「未分类支出计入总预算」。
2. **首个新增账户未设为默认账户**
   - 现象：`openAccountForm` 里 `defaultAccountId: input.id` 读到 undefined，首个账户未自动设为默认。
   - 修复：先 `const id = Utils.genId()` 再引用；新增渲染层测试。
3. **A6 休息日暂停排程缺少 UI 开关**
   - 现象：`restDayAffectsPlanning` 有逻辑但设置页无开关。
   - 修复：设置页日历卡片补第 4 个复选框。
4. **E2E 定位与表单问题**
   - `.week-col` 应为 `.week-cols`；`clickBtn('周'/'日')` 误匹配导航「周回顾 / 今日规划」，改为作用域限定在 `#view-schedule .seg` 的 `segBtn()`；转账表单必须选 `toAccountId` 才能提交（否则 modal 不关闭拦截后续点击）。

### 3.3 环境问题（非代码缺陷）

- NSIS 静默重装挂起：二次 `/S` 静默安装触发 assisted（`oneClick:false`）卸载器需 GUI/提权而挂起。改用 `dist/win-unpacked/日程管理.exe`（与安装包同源打包代码）完成冒烟验证，安装器本身已成功构建并曾成功安装。

### 3.4 测试结论
