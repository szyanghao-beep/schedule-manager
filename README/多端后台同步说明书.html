第 1 章　这是什么？同步是怎么工作的

什么是多端同步

「日程管理」可以同时运行在电脑（Windows/macOS）和安卓手机上。多端同步的意思是：你在电脑上记的日程、待办、收支流水，手机上也能看到；反过来，手机上记的，电脑上也有。两端数据保持一致。

同步中心在哪里（方案 A）

v2.3.1 起，我们把同步服务器直接内嵌进了电脑端 App：

🖥 电脑端 = 同步中心

电脑端 App 启动时，在本机同进程跑起一个 8787 端口的同步服务。它负责保存「云端」数据、做两端数据的合并与仲裁。

📱 手机端 = 客户端

手机通过局域网连到电脑的 8787 端口，把本地改动推上去、把别人的改动拉下来，完成同步。

✅ 这样设计的好处
无需单独安装 Node.js、无需打开命令行、无需手动启动服务。电脑端 App 一开，同步中心就跟着起来了；关机时它也一起退出，端口自动释放。

前提条件

1
电脑和手机在同一个局域网——通常就是连同一个 Wi-Fi / 路由器（家庭或办公网络）。
2
电脑端 App 正在运行，并且已开启「本机同步服务」（见第 2 章）。
3
知道电脑的局域网 IP，手机端填这个地址（见第 3 章）。

第 2 章　在电脑端开启同步服务

只需设置一次，之后每次开机自动生效。

1
打开电脑端 App，进入「设置」。
2
找到「本机同步服务（同步中心）」卡片。
3
勾选「启用本机同步服务」。界面随即显示「运行中」，并给出「手机端地址 http://<本机局域网IP>:8787」。
4
（可选）取消勾选即可停止服务；下次重新勾选又会启动。
💡 记住这几件事
  • 自动启动：勾选状态会保存到本机，下次开机、打开 App 即自动拉起 8787 服务，不用再手动操作。
  • 自动生成密钥：服务首次启动会在本地生成一个随机 JWT 密钥（sync-server.secret），用于加密登录令牌，无需你手动配置。
  • 数据独立存放：同步数据保存在 sync-server.db 中，与桌面端本地数据分开，互不干扰。
⚠️ 如果显示「启动失败」
通常是 8787 端口被其它程序占用（例如你之前手动跑过旧版后端）。请关闭那个程序，或重启电脑后再试。排查步骤见第 5 章。

第 3 章　查看本机地址

手机要连的是电脑在局域网里的 IP 地址。有两种方式获取：

方式一：直接在设置页看（推荐）

开启同步服务后，设置页的卡片上会直接显示：

手机端地址
http://（电脑当前局域网IP）:8787

把这段地址原样填到手机端即可。IP 会随电脑、网络变化（换电脑、换路由器、重启路由器后都可能不同），所以请以程序里显示的为准；手机端也可以直接点「🔍 自动查找电脑」自动找到，不用手抄。

方式二：命令行查看

Windows 打开「命令提示符」输入 ipconfig，找到「IPv4 地址」；macOS 输入 ifconfig，找 inet 192.168.x.x。取其中的 IP，再拼上 :8787。

地址说明

要素含义示例
http://局域网内用普通 HTTP（内网明文即可）—
IP电脑的局域网 IPv4 地址（会随网络变化，以程序显示为准）见程序「本机同步服务」
:8787同步服务端口（固定）8787
⚠️ 不要填 127.0.0.1
127.0.0.1 代表「本机自己」，手机填它是连手机自己，永远连不上电脑。一定要填电脑在局域网里的真实 IP（一般是 192.168.x.x 或 10.x.x.x）。

第 4 章　在安卓手机上连接并同步

1
手机安装并打开「日程管理」安卓端。
2
进入「设置 → 多端同步」，点「连接本机」自动填入 http://127.0.0.1:8787（本机自连推荐——回环地址不受网段变化影响）；若要连另一台电脑，点「填入局域网地址」或手输。
3
填一个用户名 + 密码，点「注册并登录」（首次注册；以后直接登录）。
4
点「立即同步」。之后两端每次改动会自动同步；也可随时手动点「立即同步」。

同步机制（简要）

  • 记录级增量：每条日程/待办/流水单独同步，而不是整份文件覆盖，效率高、不冲突。
  • 软删除：删除只是打上「已删除」标记，防止旧数据在一端复活。
  • 编辑时间仲裁：同一条记录被两端改动时，以「最后编辑时间」较新者为准。
🔐 账号与密钥
登录令牌用本机自动生成的密钥加密，仅保存在你的电脑上；同步数据只在本机局域网内流转，不上传任何第三方服务器。

第 5 章　常见问题与排查

Q1：手机连不上，提示「网络错误 / 连接超时」

1
确认电脑端 App 已开启同步服务、显示「运行中」。
2
确认手机和电脑连同一个 Wi-Fi（手机别用流量）。
3
确认地址是电脑的真实局域网 IP，不是 127.0.0.1。
4
检查防火墙：Windows 首次运行可能弹出「允许访问专用网络」的提示，勾选允许。

Q2：设置页显示「启动失败」

通常是 8787 端口被占用。可用命令 netstat -ano | findstr 8787 查到占用进程 PID 并结束它；若不确定，直接重启电脑最省事。

Q3：出门/断网后，手机还能用吗

可以。两端各自有本地完整数据，离线也能正常查看和新增；等回到同一局域网、电脑端 App 打开时，再点「立即同步」即可把离线改动补上。

Q4：换了一台电脑，手机要重新配置吗

要。同步中心（数据）就在原电脑的 sync-server.db 里，换电脑后新电脑是全新的同步中心。手机端把服务器地址改成新电脑的 IP，重新注册登录即可。

Q5：想在外网（公司→家里）同步怎么办

本方案默认只在同一局域网内同步。若需跨网络，请把后端部署到一台常在线、有公网地址（或内网穿透）的设备上，见第 6 章。

第 6 章　进阶：把后端放到 NAS / 常在线服务器

如果你希望不依赖电脑开机，随时随地同步（含外网），可以把后端独立部署到一台常在线设备（NAS、云服务器、树莓派等）。

独立后端（Node 方式）

项目自带可独立运行的 Node 后端（server/ 目录），与内嵌版是同一套代码：

启动命令
cd server
npm install
npm start            # 监听 0.0.0.0:8787，自动生成密钥

随后电脑端和手机端都把「服务器地址」指向这台设备的地址即可，不再依赖电脑端 App 开关。

两种模式对比

对比项内嵌式（方案 A，默认）独立后端（进阶）
部署难度零，勾选即用需装 Node、会基本命令行
同步范围同一局域网局域网 / 外网（配公网或穿透）
依赖电脑端 App 需运行部署设备需常在线
适用场景个人、家里/办公室自用多设备、跨网络、团队
⚠️ 外网部署请注意安全
独立后端默认无 HTTPS，若暴露到公网，请务必置于反向代理（Nginx/Caddy + TLS）之后，并设置强密码。
